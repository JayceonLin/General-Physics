# 物理公式星系

大學普通物理 100 條公式的關係圖。點進任一章，就能看到每條公式的定義、符號意義與用途，以及它和前後章節公式的關係（推導、特例、應用、類比、搭配、比較），每條關係都附一句說明。公式詳細頁有符號拆解、推導、互動模擬與課本例題，每章另有練習題。

- 範圍：依三次段考分成 16 章（Ch5–9、Ch10–14 與 Ch32、Ch15–19）
- 內容：改編自 Wolfson《Essential University Physics》課堂投影片；Ch18、Ch19 為補充內容
- 技術：單一 `index.html`，KaTeX 排版公式、SVG 畫關係線、Canvas 繪製 17 個模擬，學習進度存在瀏覽器

線上版：https://jayceonlin.github.io/General-Physics/
